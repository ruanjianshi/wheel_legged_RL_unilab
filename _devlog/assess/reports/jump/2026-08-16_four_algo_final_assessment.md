## 2. 逐阶段详细姿态

### 2.1 纯PPO（5/7）— 受控小跳，高度是固有极限
```
站立 z=0.52 up=1.0 ✅  下蹲 0.524 膝屈0.08 ⚠️不蹲
空中 16步 跳高0.089m ⚠️ up=0.999直立  收腿轮速6.1 ✅
落地 冲击温和 ✅ 缓冲✅  落地轮速12.6 ⚠️打滑
恢复 |gyro|=0.89 ✅ 左右高低腿⚠️
```
**姿态问题**: ① 下蹲蓄力不足（膝屈 0.08）② 跳高 0.089m 远低于 0.20 ③ 落地轮打滑。
**性质**: 无参考结构的固有极限（7 轮迭代确认，成功率 100% 但高度受限）。

### 2.2 SRL（7/7）— 最佳
```
站立 ✅  下蹲 0.246m 膝屈1.83 ✅深蹲(但过深→"倒地"标) 
空中 63步 跳高0.224m up=0.997 ✅  收腿轮速4.1 ✅
落地 冲击vz=-2.34 ⚠️偏大 缓冲最低0.257 ✅  轮速3.2 ✅
恢复 |gyro|=1.45 ❌晃动 左右高低腿⚠️
```
**姿态问题**: ① 深蹲过深（0.246m < 0.25 被标"倒地"，有失稳风险）② 恢复晃动（|gyro| 1.45）③ 落地冲击偏大。
**性质**: 达标但深蹲/落地/恢复有可优化空间。

### 2.3 PPO+VMC（6/7）— 跳高最高
```
站立 ✅  下蹲 0.468 膝屈0.36 ⚠️下蹲不足
空中 33步 跳高0.304m up=0.990 ✅  收腿轮速2.5 ✅
落地 冲击温和 ✅ 缓冲0.549 ✅  轮速1.1 ✅不空转
恢复 |gyro|=0.86 ✅稳定  左右高低腿⚠️
```
**姿态问题**: ① 下蹲蓄力不足（膝屈 0.36，限制了更高跳跃）② 空中左右高低腿。
**性质**: 跳高达标 + 恢复稳定，主要差距在下蹲深度。

### 2.4 SRL+VMC（6/7）— 跳高略低于阈值
```
站立 ✅(摇摆⚠️)  下蹲 0.370 膝屈0.76 ✅深蹲
空中 52步 跳高0.183m ⚠️ up=0.997  收腿轮速2.3 ✅
落地 冲击温和 ✅ 缓冲0.450 ✅  轮速5.5 ⚠️轻微打滑
恢复 |gyro|=1.54 ❌晃动
```
**姿态问题**: ① 跳高 0.183m 略低于 0.20 ② 恢复晃动（|gyro| 1.54）③ 落地轻微打滑。
**性质**: 接近达标，跳高和恢复稳定有提升空间。

## 3. 是否需要重新改进

| 算法 | 判定 | 理由 |
|---|---|---|
| **SRL** | ✅ 基本达标 | 7/7；深蹲过深/恢复晃动为次要问题 |
| **PPO+VMC** | ✅ 基本达标 | 6/7；跳高 0.30m 最优，恢复稳定；下蹲不足为次要 |
| **SRL+VMC** | ⚠️ **建议改进** | 跳高 0.183m 低于 0.20 阈值 + 恢复晃动 + 落地打滑 |
| **纯PPO** | ⚠️ **固有极限** | 跳高 0.089m 远低阈值；但成功率 100%，姿态正确；无参考结构的极限，改进需加参考（改变算法性质） |

**结论**: 
- **SRL / PPO+VMC** 达标，可定稿用于对比实验。
- **SRL+VMC** 建议改进（跳高 + 恢复稳定）。
- **纯PPO** 为固有极限——若要跳高 >0.20 需加 SLIP-FSM 参考（即变成 SRL 类），建议接受当前"受控小跳"或按用户意图决定。

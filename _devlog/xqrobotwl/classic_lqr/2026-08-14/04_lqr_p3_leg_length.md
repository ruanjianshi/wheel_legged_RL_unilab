## 实现

**膝高度伺服** (controller.py phase>=3):
```
膝目标 = 补偿基座膝 + height_kp·(h_cmd−z) + height_kd·ż + height_ki·∫(h_cmd−z)dt
q_leg[2] += knee_adj  (L膝);  q_leg[5] -= knee_adj  (R膝镜像)
安全钳位: L_pitch>0.05, R_pitch<-0.05 (防 kp=60 下垂塌陷)
```

**关键调试**:
1. **L0-IK 不可靠**: 目标没补偿 kp=60 下垂 → L_pitch 塌到 0.016 触发 thigh_collapsed (0.04s 倒)。改为补偿基座 + 膝伺服。
2. **物理可达范围限制**: 腿长 L0∈[0.20,0.52] → 机身高度可达 ~0.48-0.55。命令 0.65/0.75 不可达 (腿拉不动)。调度范围调整为 0.48-0.55。
3. **膝伺服与平衡张力**: 强膝响应 (kh>2) 会破坏平衡 → 用温和 kh=0.8 + 积分。

## 遗留与限制 (如实)

- **高度范围受限**: kp=60 位置伺服腿 + 腿长范围 → 只能调 ~0.48-0.55 (非 §7.2 的 0.45-0.85)。
- 若要全高度范围, 需扭矩腿 (软件高刚度 PD) 或 VMC 腿控 — 超出经典平衡控制器当前范围。

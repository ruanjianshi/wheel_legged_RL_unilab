## 实现

**控制律** (controller.py phase>=2):
```
w_cmd = -(q_theta·θ + q_theta_dot·θ̇ + q_v·(v−v_ref) + q_z·z_int)   # z_int=∫(v−v_ref)dt
w_cmd = -(q_theta·θ + ...) 前倾→负 = 后驱 (修正方向)
```

**关键修正** (调试中发现):
1. **v 项用 (v−v_ref) 而非 v**: 原 `q_v·v` 在追踪时刹车 (速度>0 就减), 改误差项直接驱动。
2. **指令斜坡** (cmd_ramp_s=1.5): 阶跃命令 (0.5→−0.5) 产生暴力刹车→倒; 斜坡 1-2s 消除。
3. **yaw 差分符号**: `w_L=−(w_c+δ), w_R=(w_c−δ)` (R 侧减, 原写成加 → 转向不生效/反向)。
4. **q_z=15** (积分, 提速追踪)。

**vyaw 转向**: vyaw=0.2 可转向且存活 (25s); 高速转向 (≥0.3) 会倒 (差速转向削弱平衡权威 + 轮打滑)。低速可用。

## 遗留

- 高速转向 (vyaw≥0.3) 不稳 — 差速时轮打滑削弱平衡。可后续用转向-平衡解耦或更慢转向曲线。
- 指标 vx_rmse 已改为稳态口径 (排除命令变化后 1s 瞬态)。

# 09 — FSM 参数修复 + 预热逻辑 + 自适应增益

## 日期
2026-07-22（续 08）

## 来源
继续修复 Wheeled-SRL 训练问题，08 日志中发现的问题深入修复。

## 问题描述

### 1. FSM 过渡条件全部被超时抢占（08 评估发现）
- 下蹲→蹬地：110ms 超时触发，机器人来不及下蹲（目标 500ms+）
- 蹬地→飞行：60ms，腿还没伸直就进飞行
- 飞行→着陆：z<0.85m 太宽松，1m 高空就判"着陆"
- 首次跳跃：起飞时 vz=-1.54m/s，向下砸进地面不是跳起来
- 链式弹跳：后续循环 z 在升高不是降低，变成弹跳而非蹲跳

### 2. 论文表 1 实现不符
- 状态 1（跳跃加速）缺少车轮主动驱动 → 论文要求"主动驱动提供额外冲量"

### 3. 预热阶段过短（iter 3 vs 预期 3000）
- `_warmup_cutoff = warmup_iters * 24 = 72,000`（单 env 步数）
- 但 `_total_env_steps` 按所有 env 累计：每 step += 1024
- 导致预热在 3 iter 结束，不是 3000 iter
- 对标纯 PPO：`jump_curriculum_end = 73,728,000`（= 3000 × 24 × 1024）

### 4. 站姿训练失败（ep_len=2）
- 预热阶段 feedback_gain=0.05，策略校正权仅 0.05×0.7=0.035 rad
- 纯 PPO 是 action_scale=0.6，17 倍差距
- 预热期策略没有足够的控制权学习站姿，直接倒地

## 解决方案

### 1. FSM 参数重构 (`jump_srl.py:90-115`)

| 修改项 | 旧 | 新 |
|--------|----|----|
| 状态 0 下蹲深度 | ±0.20 rad | **±0.35 rad** |
| 状态 1 蹬地力度 | ±0.30 rad | **±0.35 rad** |
| 状态 1 车轮驱动 | 0.0 | **主动驱动（论文要求）** |
| 0→1 膝关节阈值 | `>0.0 / <-0.0` | **`>0.25 / <-0.25`** |
| 0→1 超时 | 100ms | **500ms** |
| 1→2 超时 | 200ms | **400ms** |
| 2→3 近地阈值 | z<0.85m | **z<0.75m** |
| 3 缓冲斜坡 | 100ms | **200ms** |
| 4 恢复时间 | 200ms | **300ms** |

### 2. 自适应 feedback_gain (`jump_srl.py:455-471`)

```python
# 按 FSM 状态动态调整反馈增益
gain_map[fsm==-1] = 0.4   # 站立: 对标 PPO action_scale=0.6
gain_map[fsm==0]  = 0.2   # 下蹲: 适度调整
gain_map[fsm==4]  = 0.4   # 恢复: 快速恢复
gain_map[fsm in 1,2,3] = 0.05  # 蹬/飞/落: 前馈主导
```

有效校正权计算：
- 站立：0.4 × 0.7 = 0.28 rad（接近 PPO 的 0.6 水平）
- 跳跃：0.05 × 0.7 = 0.035 rad（前馈主导）

### 3. 预热步数修正 (`jump_srl.py:374-376`)

```python
# 旧: warmup_iters * 24 = 72,000 → 3 iter
# 新: warmup_iters * 24 * num_envs = 73,728,000 → 3000 iter
```

确保与纯 PPO 的 `jump_curriculum_end: 73728000` 一致。

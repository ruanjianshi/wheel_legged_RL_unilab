根因分析 (前向运动学 + 落体沉降 + 严格单轮扫描):
  1) **双膝弯到极限把两轮都收到髋部高度**: L轮 base局部 z=0.018, R轮 z=0.043
     (中立位 -0.40, 抬高了 0.4m)。双腿呈"高抬腿"前外展, CoM 保持机身中心。
  2) **竖直站不住**: 轮子在髋部高度悬空, 落体沉降(所有朝向)最终机身贴地
     (base z=0.06), 唯一接触=base_link, 轮子悬空 0.34m。
  3) **横躺支撑位形 CoM=0.635m 反而更高**: 轮子收回髋部后, 要轮触地机身
     必须离轮 0.63m → 高重心。严格单轮保持仅 0.4s (kp=60)。
  4) **用户直觉方向对, 但双膝都弯是反效果**: 弯膝降重心必须只弯"支撑腿"
     且支撑轮保持触地。单弯支撑膝(R_knee=-0.873, R_pitch=-0.2) → CoM 0.55→0.27
     真降重心, 严格单轮保持 0.2s→0.9s (主动PD), 这是真实进步。
  5) **低CoM新瓶颈: 自由腿停放**: 低重心(hip高~0.25m)时 5.1kg 自由腿无处可放:
     - L_roll=0 (腿垂下) → 自由轮触地 → 两轮作弊
     - L_roll>0 (抬腿) → CoM 侧向偏移 dy=-0.12 → 支撑轮离地(Rwheel_lost)侧翻
     - 完整搜索 (lean×R_knee×R_pitch×L_roll×L_knee, dx/dy双对齐+单轮+2s)
       → **0 个严格单轮保持 ≥1.5s**; 最优主动PD 0.91s (kp_r 需负号)
结论 (诚实):
  - **用户精确姿态(双膝都弯)不可行**: 轮子被收回, 竖直趴地/横躺CoM 0.635 高。
  - **弯膝降重心直觉本身正确**: 单弯支撑腿把 CoM 降到 0.27, 严格单轮 0.2s→0.9s。
  - **但低重心 + 重型自由腿 (5.1kg, 占整机~48%) 无法停放** → 仍 <2s 稳定。
  - 单轮平衡仍需结构改动: 减自由腿质量(轻量配重臂, OLEBOT式) / 或 RL 薄裕度尝试。

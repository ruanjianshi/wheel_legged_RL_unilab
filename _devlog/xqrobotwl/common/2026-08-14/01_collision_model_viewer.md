# 01 碰撞体模型显示工具 + 轮距左右不对称发现

## 日期
2026-08-14

## 来源
用户要求: 在 `tools/mujoco/` 构建一个显示 xqrobotwl 机器人**碰撞体模型**的工具, 检查碰撞体是否正确。

## 修改了什么
新增 `tools/mujoco/show_collision_model.py`:
- 加载 `scene_flat.xml`, 自然站姿 (standing_angles + base_z≈0.512) 复位
- 显示 group 3 碰撞体 (10 个 box/cylinder), 按连杆异色, 视觉网格 (group 2) 默认隐藏
- 键盘: C 仅碰撞 / V 仅视觉 / B 两者 / R 重置站姿 / Space 暂停
- 启动时打印碰撞体清单表: 名称/类型/尺寸/本地位姿/世界位姿/接触属性

## 哪些文件
- 新增: `tools/mujoco/show_collision_model.py`
- 用法: `uv run tools/mujoco/show_collision_model.py`

## 评估效果 (无辅助确定性验证)

碰撞体清单 (10 个): base_link 上宽箱 + 下窄箱, 髋/大腿/小腿各一 box, 轮 cylinder。
- 接触属性: 机器人全部 contype=0 / conaffinity=1 → 自身不发起接触, 但地面 contype=1
  与机器人 conaffinity=1 匹配 → **轮地接触正常生成** (平衡依赖的摩擦接触 OK)。
- 世界位姿: 轮底 z≈0.105 ≈ 轮半径 0.11 → 双轮着地 ✅

## ★ 发现: 左右轮不对称 (正确性问题)

| 项 | 左轮 | 右轮 | 差值 |
|---|---|---|---|
| 轮中心 y | -0.219 | +0.166 | **0.053 m (53 mm)** |
| 轮中心 x | -0.052 | -0.049 | 0.003 m |
| 轮中心 z | 0.105 | 0.105 | ≈0 |

- 轮距实测 |Ly−Ry| = 0.385 m; 两轮中点 y = -0.0265, **不在 base 中面** (偏左 2.65 cm)
- 根因: XML 里左右轮 body 位置本就不对称 —
  `left_link_wheel` pos=(0.224, **-0.037**, -0.199), `right_link_wheel` pos=(0.224, **+0.031**, -0.204)
- 影响评估:
  - 经典控制器 `track_width=0.38` vs 实测 0.385 → 差速偏航误差 ~1.3%, 可忽略 (k_yaw 有反馈)
  - 两轮中点偏离 base 中面 2.65 cm → 质心左右偏移可能造成轻微侧向偏置 (有待实测确认影响)
- 大腿/髋 body 也有轻微不对称 (y ±0.124 对称, 但 z/x 微小差) — 视觉网格同源, 属原始 CAD 导入差异

## 参数调整好坏
- 无参数调整; 纯显示工具, 不触碰 RL/env/控制器任何逻辑。

## 根因分析
- 碰撞体直接取自 XML body 位置 (不是独立定义的几何), 故不对称源自原始 CAD/XML 建模。
- 影响是否显著取决于用途: 显示/平衡评估不受影响; 精确 yaw 差速或侧向补偿需把 track_width
  设为实测 0.385, 或在仿真层镜像对齐左右轮。

## 验证方法
1. headless 运行表格生成, 数值与 XML 逐项核对 ✅
2. viewer 需显示器, 由用户 `uv run tools/mujoco/show_collision_model.py` 实际观察
3. 门禁: 新增脚本无 RL 依赖, `make format` 检查通过

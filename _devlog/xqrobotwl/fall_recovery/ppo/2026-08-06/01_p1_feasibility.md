# [01] 跌倒恢复 P1 可行性验证 — 贴地后空翻起身机制

**日期**: 2026-08-06
**来源**: 用户需求 — xqrobotwl 平地倒地后自恢复平衡（后空翻/单腿平衡之后的第三个技能）
**关联**: 后空翻 `backflip/ppo/2026-08-04~05`（机制同源：弹道可脚本化）、单腿 `single_leg/ppo`（start_in_balance 课程突破）

---

## 问题描述

xqrobotwl 是两轮足机器人（倒立摆）。倒地后如何自恢复平衡？项目方法论要求先做 P1 开环
可行性验证（后空翻/单腿均如此）：无策略纯前馈，回答"起身动作物理上是否可达"。

仓库中**无任何轮足机器人的跌倒恢复代码**（Sim2real 里只有别的人形机器人的关键帧起身轨迹）。

## 根因分析

轮足机器人的起身是**弹道大动作**（可开环脚本化）+ 起身后的**倒立摆平衡**（必须闭环，
RL 职责）。关键难点在于从仰卧倒地姿态把轮子移到 CoM 下方并让机身直立。
两轮在腿末端（腿长 ~0.4m + 轮 0.11m），倒地时轮子在身体两侧，无法直接支撑 →
必须靠腿部甩动产生角动量把身体翻上轮。

## 解决方案

写 `scripts/xqrobotwl/fall_recovery_feasibility.py`（开环 MuJoCo 验证），参数化
倒地姿态 + 起身 FSM（tuck 收腿 → kick 甩腿 → catch 落地缓冲 → lift 撑起），
带轨迹诊断（每 0.1s 打印 base_z/up/轮接触/位移）+ 恢复点检测（轮着地+直立>0.9）。

**参数扫描结论**（仰卧 supine, R_y(-90°), 收腿复位）:
| 变量 | 效果 |
|------|------|
| tuck 深度 0.90/0.87 | 甩到 1.4m 后翻落地近直立 (up=1.0, z=0.32) 但 lift 失衡 |
| tuck 0.85/0.80 (**胜出**) | **完整恢复: 结束倾角 4.7°** (start_z=0.12) |
| tuck 0.75 及以下 | 过度旋转, 落成俯卧 (up=-1.0) |
| start_z 敏感性 | 0.12→4.7°, 0.14→16.9°, 0.16→50.8° (恢复点仍都可达) |
| wheel_spin | 0 (制动) 最佳; 轮子加速=把身体掀飞 |

**关键发现**: 恢复点（轮着地+直立>0.9+z>0.35）在所有 start_z 下都可靠到达；
但 FF 若把机器人完全站直 (z=0.50) 会因倒立摆不稳立即前倒 → **FF 应在落地蹲姿
(z~0.35-0.40) 交棒 RL**，站直+平衡全交给 RL。

## 验证方法

`uv run python scripts/xqrobotwl/fall_recovery_feasibility.py --wheel_spin 0 --tuck_knee 0.80 --tuck_hip 0.85 --start_z 0.12`

## 评估结果

- 恢复点 t=1.02s: z=0.490, up=0.91, 轮着地
- 结束倾角 **4.7°**（纯 FF 站直到 z=0.52）
- 控制率鲁棒: 100Hz 结束 15.1°, 200Hz 16.9°, 400Hz 26.7%（恢复点都可达）
- 视频: `video/fall_recovery/` 待训练后录制

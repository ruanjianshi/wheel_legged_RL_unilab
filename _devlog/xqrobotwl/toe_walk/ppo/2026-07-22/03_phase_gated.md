# 03 — 相位门控奖励模式 (无参考轨迹)

## 日期
2026-07-22

## 来源
参考轨迹自由度低，引入相位门控奖励让策略自由探索步态。

## 设计
```
相位 0-2π:
  左摆 (0-π):   奖 左轮离地 + 左膝弯曲
  右摆 (π-2π):  奖 右轮离地 + 右膝弯曲
  全程:          奖 前向速度 + 高度 + 平衡
```

不指定关节角度，策略自由发现最优姿态。

## 新增奖励
| 奖励 | 权重 | 说明 |
|------|------|------|
| phase_swing_lift | 5.0 | 摆动相轮子离地 |
| phase_knee_lift | 3.0 | 摆动相膝盖弯曲 |
| phase_stance_contact | 2.0 | 支撑相轮子着地 |

## 实现
- `toe_walk.py`: 新增 `use_reference` flag，`_compute_ref_dof_pos` 存储 phase
- `mujoco.yaml`: 默认相位门控模式
- `mujoco_ref.yaml`: 参考轨迹版备用

# 01 — 后空翻 P1: 开环脚本物理可行性验证

## 日期

2026-08-04

## 来源

用户要求开发 xqrobotwl 新步态"后空翻"。在拉取最新代码(PPO-SRL 架构)后, 先验证物理可行性, 不进入 RL 训练。

## 问题描述

验证 18.65kg 两轮足机器人能否完成 360° 后空翻。核心难点:
1. 起跳角动量是否足够(轮腿机器人翻转需要绕俯仰轴 2π 旋转)
2. 正/反向符号约定校准
3. 开环序列对参数的敏感性

## 根因分析

- 初始脚本(轮子急加速 + 直腿蹬地)完全无法起跳: 膝只伸到 0(误差小→扭矩小), 且蹲太深(z=0.28)。
- 用 up 向量诊断发现**符号约定与直觉相反**: 正 flip=前翻, 负 flip=后翻。此前把方向判反, 导致"轮加速给后翻"的错误结论。
- 关键发现: **膝猛伸到极限(±0.87)本身就是后翻方向**(0.79m 起跳 + 280° 后翻), 轮子加速反而给前翻方向。

## 解决方案

新建 `scripts/xqrobotwl/backflip_feasibility.py`: 6 相位 FSM 开环前馈(蹲→蹬→飞→展→缓冲→恢复), 可调参数(W, crouch_hip, launch_lean, tlaunch, tflight, tuck)。

**获胜参数**: `W=0 crouch_hip=-0.25 launch_lean=0.6 tlaunch=0.25 tflight=0.45 tuck=0.7`

关键机制:
- 蹲时髋后仰(crouch_hip=-0.25): 抵消蹲的前翻倾向, 给后翻留预算
- 蹬地时髋猛后仰(lean=0.6) + 膝猛伸到极限(±0.87): 同时给升力和后翻角动量
- 飞行收腿 tuck(0.7): 减小转动惯量, 把转速放大到 ~8.7 rad/s
- 展开+缓冲+恢复: 落地直立

## 修改文件

| 文件 | 内容 |
|------|------|
| `scripts/xqrobotwl/backflip_feasibility.py` | 新建。开环后空翻 FSM 脚本, 含相位快照、flip_progress 积分、轮离地检测、扭矩峰值测量、`--render` 离屏渲染(ffmpeg 组 mp4) |

渲染用法: `uv run python scripts/xqrobotwl/backflip_feasibility.py --render <目录或xxx.mp4>` → 侧面视角 100fps mp4。归档到 `video/<步态>/` 分类管理(见 `video/README.md`)。获胜参数视频: `video/backflip/2026-08-04_01_开环可行_360°落地3.8°_lean06_ch-025.mp4`。

## 验证方法

MuJoCo 3.8 本地跑脚本, 结果:

| 指标 | 值 |
|------|-----|
| 翻转进度 | **-6.28 rad = 正好 360°** |
| 落地倾角 | **3.8°** (up 向量 ≈ (0,0,1)) |
| 腾空时间 | **0.41s** (轮中心>0.35 计 82 步) |
| 最高点 | 0.72 m |
| 关节扭矩峰值 | 膝 94 N·m, 髋 50 N·m |
| 轮中心高度范围 | 0.09~0.78 m (站立 0.29) |

## 评估结果

鲁棒性扫描(launch_lean × crouch_hip, 16 组合): 甜蜜区 `lean=0.6, ch=-0.20~-0.25` 稳定 ✅(100-103% 旋转, 落地 <13°), 其余组合大多塌到 75-83% 且落地 >60°。**开环序列对参数敏感**, 这是 P2/P3 用 FSM 前馈 + PPO 强化鲁棒性的直接动机。

方向结论: 负 flip = 后空翻。膝蹬 + 髋后仰 = 后翻; 轮子加速 = 前翻。

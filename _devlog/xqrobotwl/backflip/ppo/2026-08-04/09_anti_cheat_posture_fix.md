# 09 — 防取巧: 站立高度 + 倒地判定修正

## 日期

2026-08-04

## 来源

用户反馈: 后空翻成功但视觉效果差, 模型取巧 — 翻完后蹲低 (z=0.41, 膝盖弯 0.44), 且视频中机身几乎碰地都不重置。

## 问题描述

1. **蹲低取巧**: 翻完后机器人蹲着 (z=0.41, 膝盖 0.44), 因为 stand_balance 只奖"不倒"(up), 不奖"站直"
2. **倒地判定太松**: max_tilt_deg=75 (几乎平躺), 站立态(state -1)无倾角终止
3. **calf 终止死代码**: 膝范围 ±0.87, 阈值 1.8 永不触发

## 根因分析

| 问题 | 根因 |
|------|------|
| 蹲低 | 无高度奖励, 策略发现"翻完+蹲着"得分最高 |
| 不重置 | 75° 阈值 + 站立态不终止 |
| calf 死代码 | 阈值 1.8 > 关节范围 0.87 |

## 解决方案

1. **stand_height 奖励** (scale 3): 站立态(-1/4/5)奖励高度接近 0.65, 惩罚蹲低
2. **max_tilt_deg** 75→50, 站立态也纳入倾角终止 (grounded_fail 含 -1)
3. **calf_extreme** 阈值 1.8→0.8, 且仅站立/恢复态(-1/5)触发 (蹲姿/飞行深弯正常)

## 修改文件

| 文件 | 内容 |
|------|------|
| `src/unilab/envs/locomotion/xqrobotwl/backflip.py` | 加 `_reward_stand_height`; 终止: 站立态含倾角终止, calf 0.8 且仅 -1/5 |
| `conf/ppo/task/xqrobotwl_backflip_flat/mujoco.yaml` | stand_height=3.0, max_tilt_deg=50 |

## 验证方法

- 纯 ff 翻转恢复 (84% = 5.3 rad, 之前被 calf 误杀到 0)
- resume 续训后验证: 翻完站直 (z≈0.65, 膝盖≈默认), 不蹲低
- 倾倒 >50° 持续 0.4s 会终止

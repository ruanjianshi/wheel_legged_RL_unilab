# 01 修复髋关节对称性 + 构建评估框架

**日期**: 2026-07-01  
**来源**: 训练评估发现 Vx/Vy 严重耦合  
**关联**: [02 全量评估](02_full_eval_16200.md)

---

## 问题描述

平坦行走 PPO 策略（iter≈10000）出现严重的 Vx/Vy 耦合：
- 指令 `Vx=+0.6` 时，实际 `Vy≈+0.65 m/s`（横向漂移）
- `tracking_lin_vel` 奖励偏低（1.18），无法提升
- 机器人向前走时会自行侧移

## 根因分析

**髋关节默认角度不对称**。代码注释写"双髋外展 0.1"，但实际：

| 关节 | 标定值 | 物理方向 | 意图 |
|------|--------|---------|------|
| L_hip | +0.1 | **内缩**（收向中线） | 外展 |
| R_hip | +0.1 | **外展**（撇离中线） | 外展 |

两个髋关节旋转轴均为 `axis="1 0 0"`（body-frame X=forward），根据右手法则：
- L_hip (+Y 侧): 正旋转 → 内缩
- R_hip (+Y 侧): 正旋转 → 外展

同号产生相反物理效果 → 左腿内收、右腿外展 → 支撑面右偏 → 向前推地时产生净横向分力。

## 解决方案

将 L_hip 从 +0.1 改为 -0.1（外展），使双髋对称外展：

| 阶段 | L_hip | R_hip | 效果 |
|------|-------|-------|------|
| 改前 | +0.1 (内) | +0.1 (外) | 不对称 |
| **改后** | **-0.1 (外)** | **+0.1 (外)** | **对称外展** |

> 尝试过对称内收(+0.1, -0.1) — 静态倒塌。对称外展虽然静止时也会倒塌，但 RL 策略能主动补偿。

## 修改文件

| 文件 | 改动 |
|------|------|
| `src/unilab/envs/locomotion/xqrobotV2/base.py:31` | `DEFAULT_LEG_ANGLES` 第 0 个元素: 0.1→-0.1 |
| `src/unilab/assets/robots/xqrobotV2/scene_flat.xml:25` | keyframe 左腿行 qpos: 0.1→-0.1 |
| `src/unilab/assets/robots/xqrobotV2/locomotion_task.xml:5` | 同上 |

## 验证方法

重新训练（iter 1→14500），通过评估脚本检测 Vx/Vy 解耦：

```
Fwd vx=+0.6 → Vy=-0.064  (串扰仅 0.06, 之前 0.65)
Fwd vx=+0.3 → Vy=-0.043  (串扰仅 0.04)
```

## 评估结果

- Vx/Vy 解耦成功（Vy 串扰从 0.65 降到 <0.06）
- 前向跟踪 0.3-0.4 m/s 优秀（RMSE < 0.05）
- 横向移动和后退仍需改善

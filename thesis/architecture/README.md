## 三要素

- **多地形**: 平坦 (平面) / 不平坦 (斜坡·碎石·不规则·弧度) / 特殊 (台阶·独木桥·木桩)
- **多步态 (8种)**: 滚动行走 · 抬腿行走 · 侧向行走 · 跳高跳远 · 抬腿上台阶 · 后空翻 · 单腿平衡 · 跌倒恢复
- **多算法**: 单 RL (PPO/SAC/N3PO) + 融合 (PPO+VMC / PPO+SLIP / SLIP+PPO+VMC / PPO+MPC)

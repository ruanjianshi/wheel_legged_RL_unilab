# scheduler — 学习式统一调度器 (第2阶段 · 整合)

**论文章节**: 第7章 (核心创新章) | **状态**: ⏳ 未开发

"分训-整合"两阶段的**第2阶段**: 将 8 个步态专家整合为可在混合地形上自动切换步态的统一系统。

## 规划设计 (来自实施计划 §四)

| 项 | 设计 |
|----|------|
| 建模 | 分层强化学习 (选项框架): 8 专家 = 底层选项集合, 调度策略 = 高层决策 |
| 输入 | 地形感知 (前向地面高度剖面、轮地接触、地形类型估计) + 本体状态 (位姿、速度、当前专家) |
| 输出 | 对 8 专家的选择概率 (softmax 门控) |

> 其中专家 8 跌倒恢复为**应急恢复选项**: 主步态失稳跌倒时切入, 恢复站姿后交还控制权。
| 奖励 | $r^h_t = w_{prog}\mathbb{I}_{progress} + w_{speed}v_{track} - w_{pen}(\mathbb{I}_{fall} + \lambda\mathbb{I}_{osc})$ |

## 关键机制

- **硬/软门控**: 硬门控直接激活最优专家 (高动态); 软门控加权混合 (切换平滑)
- **滞回切换**: 选择概率连续超过阈值并维持 ΔT 才切换, 避免地形边界抖振
- **能量指标融合**: 辅助判别当前步态是否仍稳定, 抑制误选
- **课程式训练**: 单地形 → 双地形交替 → 完整混合地形
- **专家冻结/联合微调**: 先冻结专家训练调度器, 收敛后联合微调

## 要解决的核心问题 (论文 §二)

| 问题 | 调度器的应对 |
|------|-------------|
| 灾难性遗忘 | 专家参数解耦分训, 调度器只"选择"不覆盖专家参数 |
| 奖励冲突 | 专家奖励与调度器目标分离的分层奖励结构 |
| 局部最优 | 细粒度多维评估 + 领域随机化 |

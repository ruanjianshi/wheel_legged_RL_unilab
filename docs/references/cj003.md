## 一、项目概述

CJ-003 是 XqRobotV2 的**直接参考设计来源**，同样是 8DOF 轮腿双足机器人。基于 Genesis 仿真器，支持 URDF/MJCF 双格式、地形训练、课程学习、sim2sim 迁移。

---

## 二、机器人形态

### 2.1 关节布局 (8DOF)

| 索引 | CJ-003 名称 | XqRobotV2 名称 | 类型 | 轴 |
|------|------------|---------------|------|-----|
| 0 | left_hip_joint | left_joint_1 | hinge | `1 0 0` (roll) |
| 1 | left_thigh_joint | left_joint_2 | hinge | `0 1 0` (pitch) |
| 2 | left_calf_joint | left_joint_3 | hinge | `0 1 0` (pitch) |
| 3 | right_hip_joint | right_joint_1 | hinge | `1 0 0` (roll) |
| 4 | right_thigh_joint | right_joint_2 | hinge | `0 1 0` (pitch) |
| 5 | right_calf_joint | right_joint_3 | hinge | `0 1 0` (pitch) |
| 6 | left_wheel_joint | left_joint_wheel | hinge | `0 1 0` |
| 7 | right_wheel_joint | right_joint_wheel | hinge | `0 1 0` |

### 2.2 尺寸

| 部件 | 长度 |
|------|------|
| 大腿 | 300mm |
| 小腿 | 300mm |
| 轮径 | 200mm |

### 2.3 默认站姿

```
default_joint_angles = [0, 0, 0, 0, 0, 0, 0, 0]  # 全部 0
base_init_pos = [0, 0, 0.7]  # 底座 0.7m
```

**全部关节初始化为 0** —— 双腿笔直下垂，髋关节不外展。与 XqRobotV2 不同（XqRobotV2 髋=0.1）。

### 2.4 髋关节限制（不对称设计）

| 关节 | 下限 | 上限 | 说明 |
|------|------|------|------|
| left_hip | **-0.5** | **+1.0** | 允许外展 +1.0 (57°)，限制内收 -0.5 (-29°) |
| right_hip | **-1.0** | **+0.5** | 允许外展 -1.0 (57°)，限制内收 +0.5 (29°) |

设计意图：**双腿可以外展但不能内收太多**，防止腿部碰撞机身。

## 四、训练设计

### 4.1 奖励函数

| 奖励 | CJ-003 | XqRobotV2 | 类型 |
|------|--------|-----------|------|
| tracking_lin_x_vel | +1.5 | +1.5 | exp(-err²/0.3) |
| tracking_ang_vel | +1.5 | +1.5 | exp(-err²/0.3) |
| lin_vel_z | -0.2 | -0.2 | err² |
| ang_vel_xy | -0.02 | -0.02 | err² |
| tracking_leg_length | **-2.0** | 无 | 膝关节跟踪 |
| projected_gravity | **-14.0** | **-10.0** | gravity_xy² |
| joint_action_rate | -0.1 | -0.1 | Δaction² |
| wheel_action_rate | -0.015 | -0.005 | Δwheel² |
| similar_calf | -0.3 | -1.0 | 小腿对称 |
| tsk | -2.0 | -2.0 | 髋差动 |
| **feet_distance** | **-100.0** | -1.0 | 轮距 [0.3, 0.6]m |
| survive | +1.0 | +1.0 | 存活 |
| dof_acc | -1e-7 | 无 | 加速度 |
| dof_force | -1e-6 | 无 | 力矩 |

### 4.2 关键差异

1. **CJ-003 orientation = -14.0**（比 XqRobotV2 的 -10.0 更严），但髋=0.0 不倾斜，不需要那么强的姿态约束
2. **feet_distance = -100.0** 但配合 `only_positive_rewards = True`（裁剪负值），实际不生效
3. **tracking_leg_length** 独立约束膝关节位置（XqRobotV2 没有）

### 4.3 命令系统

| 维度 | CJ-003 | XqRobotV2 |
|------|--------|-----------|
| vx | [-2.0, 2.0] | [-0.6, 0.6] |
| vy | [0, 0] | [-0.3, 0.3] |
| vyaw | [-12.0, 12.0] | [-1.0, 1.0] |
| tsk | [-0.3, 0.3] | [-0.1, 0.1] |
| height | — | [0.45, 0.85] |

CJ-003 的速度范围**远大于** XqRobotV2（vx 2.0 vs 0.6），但在 B 站视频中的实际效果是平稳慢走。

### 4.4 课程学习

| 参数 | 值 |
|------|-----|
| 初始比例 | 30% |
| vel_step | 0.001 |
| ang_vel_step | 0.002 |
| 更新间隔 | 25 steps |
| 误差阈值 | 0.35 |
| 方向 | **仅正向扩展**（XqRobotV2 已改为对称） |

### 4.5 域随机化

完全开启：质量 ±1.5kg、COM 偏移 ±0.03m、地面摩擦 [0.2, 1.6]、KP/KD [0.8, 1.2]。

### 4.6 终止条件

- 俯仰/横滚 > [20°, 60°]（动态阈值）
- 本体/大腿/小腿触地 → 立即重置
- **无 thigh_collapsed / calf_extreme 固定阈值**（XqRobotV2 有）

## 六、对 XqRobotV2 的借鉴

### 已采用
- 轮子速度控制 (kv → 1.0, 待提高到 5.0)
- 100Hz 控制频率
- 课程学习对称化
- 全腿对称约束 (similar_calf)

### 可借鉴
- **髋关节限制**：非对称外展限制 [−0.5, +1.0] / [−1.0, +0.5]，防止腿碰撞机身
- **tracking_leg_length**：独立膝关节跟踪奖励，约束腿长范围
- **15 帧观测历史**：比 9 帧提供更多时序信息
- **feet_distance 配合 only_positive_rewards**：用大权重 + 裁剪实现"软约束"

### 不适合借鉴
- 髋=0.0：XqRobotV2 结构需要外展 0.1，改为 0.0 会崩溃
- Genesis 框架：UniLab 已选定 MuJoCo 后端
